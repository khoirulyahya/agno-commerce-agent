Code Anatomy

Hanya 3 Bagian Utama di Agno

1. Model Provider:

Pilih mau pakai OpenRouter (9router) untuk cloud atau Ollama untuk offline tanpa biaya token.

2. Tools (Python Functions):

Cuma fungsi Python biasa + Docstring. Agno otomatis ubah fungsi jadi Schema JSON Tools standar OpenAI!

3. Agent Controller:

Beri instruksi role (system prompt), satukan tools dan model, lalu panggil agent.run().

agno_transaction_demo.py 
from agno.agent import Agent
from agno.models.openrouter import OpenRouter
# ATAU: from agno.models.ollama import Ollama

# 1. BIKIN TOOL TRANSAKSI (FUNGSI PYTHON BIASA!)
def beli_diamond_ml(user_id: str, zone_id: str, paket: str) -> str:
    """Membuat transaksi top-up Mobile Legends untuk customer.
    Args:
        user_id: ID akun ML (contoh: '12345678')
        zone_id: Zone ID 4-5 digit (contoh: '2026')
        paket: Nama paket ('86 Diamond', '296 Diamond')
    """
    invoice_id = f"INV-ML-{user_id[:4]}-99"
    return f"Order #{invoice_id} berhasil dibuat untuk MLBB {user_id} ({zone_id}). Total: Rp 21.000. Bayar via QRIS."

# 2. INISIALISASI AGENT
agent = Agent(
    model=OpenRouter(id="google/gemini-2.5-flash"), # atau Ollama(id="llama3.1")
    tools=[beli_diamond_ml],
    instructions=["Kamu adalah Customer Service AI AgnoCommerce. Bantu user order diamond dengan ramah dan konfirmasi detail sebelum transaksi."],
    show_tool_calls=True
)

# 3. JALANKAN
agent.print_response("Saya mau beli 86 diamond dong, ID ku 88392019 zone 2102", stream=True)
Model Routing & Cost

Pilihan Model: OpenRouter / 9Router vs Ollama Lokal

Bagaimana memilih model terbaik sesuai budget & spesifikasi server client.

🌐 OpenRouter / 9Router (Cloud)

Production Grade
  • ✓ Akurasi Tool Calling Tinggi: Model seperti Gemini 2.5 Flash, Claude 3.5 Haiku, atau GPT-4o-mini jarang salah mengisi parameter fungsi.
  • ✓ Server Murah (0 GPU): Backend server client cukup VPS biasa 1-2 vCPU $5/bulan karena komputasi LLM di cloud.
  • ✓ Banyak Model Free/Murah: Ada tier gratis (`meta-llama/llama-3.3-70b-instruct:free`, Gemini Flash murah meriah).
OPENROUTER_API_KEY=sk-or-v1-xxxxx
DEFAULT_MODEL=google/gemini-2.5-flash

💻 Ollama (Local Server)

Zero Token Cost
  • ✓ 100% Gratis & Offline: Tidak ada tagihan bulanan per token, data user tetap privat di server internal.
  • ✓ Cepat untuk Development: Sangat enak buat uji coba fungsi tool calling di laptop kamu sekarang.
  • ⚠ Butuh Server Spek Tinggi: Di production butuh VPS dengan RAM minimal 8-16 GB atau GPU untuk model Llama-3.1 / Qwen2.5.
OLLAMA_HOST=http://localhost:11434
DEFAULT_MODEL=llama3.1:latest
Production Security & UX

Cara Handle Anonymous User & Anti-Spam / Bot

Menjawab pertanyaanmu: "Gimana website landing page tanpa login handle transaksi dan spam?"

1

Anonymous Session UUID

Saat user pertama kali buka web AgnoCommerce, JavaScript di browser otomatis generate session_id = crypto.randomUUID() dan disimpan di localStorage.

Setiap chat mengirim session_id ini, jadi AI tetap ingat riwayat order user tersebut tanpa perlu login.

2

IP & Fingerprint Rate Limit

Di FastAPI kita pasang Token Bucket Rate Limiter: Maksimal 10 pesan chat per menit per IP address.

Jika ada bot melakukan spam, server langsung mengembalikan status HTTP 429 Too Many Requests sebelum menyedot kuota LLM.

3

2-Step Confirmation

Tool transaksi tidak langsung mendebit uang secara liar. AI diprogram untuk selalu menampilkan kartu ringkasan invoice:

"Apakah data akun ML 88392019 (2102) & 86 Diamond sudah benar? [Konfirmasi & Bayar]"
