Core Agno Concepts

The 3 Pillars of an Agno Agent

Unlike raw LLM wrappers, building production agentic systems in Agno boils down to 3 simple declarative components.

1. Model & Failover Provider

Multi-account Gemini key pool with seamless fallback to OpenRouter or Ollama.

2. Function Tools

Plain Python functions automatically converted into schema tools for the agent.

3. Memory & Sessions

Persists user preferences, order context, and conversation history across turns.

Zero Downtime Resilience

Key Pool & Multi-Provider Failover

How LibraBot avoids 429 Rate Limit errors and stays 100% online.

🔄

Gemini Multi-Account Key Pool

Rotates across multiple Gemini API keys automatically. If one key hits quota or 429, the failover wrapper immediately retries on the next key in milliseconds.

🌐

OpenRouter / Ollama Fallback

If the entire primary pool is exhausted, the system seamlessly falls back to OpenRouter or local Ollama instances without crashing the user session.

Production Guardrails

Session Management & Bot Protection

🔑

Anonymous UUID Sessions

Allows users to shop and chat immediately without requiring pre-registration.

⏱️

IP Rate Limiter

FastAPI in-memory limiter (15 requests/min) to prevent spam attacks.

✅

Order Confirmation Guardrail

Agent always validates buyer data, book SKU, and amount before creating invoices.
